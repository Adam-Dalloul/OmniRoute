## පිරිසිදුකාරකය ස්ථාපනය කරන්න (එක් වරක් පමණක්, යන්ත්රය මත)

```bash
scp scripts/ops/runner-janitor.sh root@192.168.0.113:/opt/omniroute-ops/runner-janitor.sh
ssh root@192.168.0.113 'chmod +x /opt/omniroute-ops/runner-janitor.sh; apt-get install -y lsof'
# cron (root): සෑම මිනිත්තු 30කට වරක්, /var/log/runner-janitor.log වෙත ලොග් කරන්න
*/30 * * * * MAX_ACTIVE_RUNNERS=6 /opt/omniroute-ops/runner-janitor.sh >> /var/log/runner-janitor.log 2>&1
```

`lsof` අවශ්ය වේ: පිරිසිදුකාරකය යම් path එකක් ඉවත් කිරීමට පෙර, විවෘත ගොනුවල එක් snapshot එකක් භාවිතයෙන් එය අක්රිය බව තහවුරු කරයි. එම මෙවලම නොමැතිව එය කිසිවක් ඉවත් නොකරන අතර ඒ බව දන්වා නවතී (exit 1). ඕනෑම වෙනසක් පළමුව `--dry-run` සමඟ අත්හදා බලන්න — එය සිදු කිරීමට නියමිත දේ හරියටම මුද්රණය කරන අතර කිසිවකට වෙනස්කම් නොකරයි.

සෑම ධාවනයකදීම එය කරන දේ: **tmpfs මත පැය 3කට** පසුව සහ disk එකේ `_work/_temp` තුළ පැය 24කට පසුව අපගේම ඉතිරි වූ දෑ (`runner-*`, `omniroute-*`, `next-build*`, `e2e-build.tar.gz`) ඉවත් කරයි; මිනිත්තු 75කට වඩා පැරණි `next-build` එකක් නවතයි (කිසිදු job එකක් එතරම් දිගු කාලයක් ධාවනය නොවේ — 2026-08-27 දින GitHub විසින් එහි job එක නැති වූ බව ප්රකාශ කිරීමෙන් පසුව එකක් මිනිත්තු 70ක් ධාවනය විය); unit එක **නතර වී ඇති** runners වල පැය 48ක් පැරණි checkouts ඉවත් කරයි; disk භාවිතය ≥ 85 %, memory PSI `full/avg60` ≥ 10 %, සහ listeners ගණන `MAX_ACTIVE_RUNNERS` ඉක්මවන විට (omniroute/other වෙන්කිරීමක් සමඟ) අනතුරු අඟවයි.
