## የጽዳት ስክሪፕቱን ይጫኑ (አንድ ጊዜ፣ በሰርቨሩ ላይ)

```bash
scp scripts/ops/runner-janitor.sh root@192.168.0.113:/opt/omniroute-ops/runner-janitor.sh
ssh root@192.168.0.113 'chmod +x /opt/omniroute-ops/runner-janitor.sh; apt-get install -y lsof'
# cron (root)፦ በየ30 ደቂቃው፣ ሎጉን ወደ /var/log/runner-janitor.log ይጻፉ
*/30 * * * * MAX_ACTIVE_RUNNERS=6 /opt/omniroute-ops/runner-janitor.sh >> /var/log/runner-janitor.log 2>&1
```

ፋይሎች ቅጽበታዊ ምስል በመውሰድ ዱካው ስራ ላይ አለመሆኑን ያረጋግጣል፤ ይህ መሳሪያ ከሌለ ምንም ነገር
አያስወግድም እና ይህንኑ ይገልጻል
(exit 1)። ማንኛውንም ለውጥ መጀመሪያ በ`--dry-run` ይሞክሩ — በትክክል ምን እንደሚያደርግ
ያትማል እና ምንም ነገር አይቀይርም።

በእያንዳንዱ ሩጫ የሚያደርገው፦ የራሳችንን ቀሪዎች (`runner-*`, `omniroute-*`,

## Runner ዩኒቶች፦ KillMode

የrunner ነባሪ `KillMode=process`፣ ዩኒት ሲቆም ወይም ዳግም ሲጀምር `Runner.Worker → npm → next-build`ን በሕይወት ይተዋል — ከምንም job ጋር ያልተያያዘ orphan build RAM እና CPUን መብላቱን ይቀጥላል። እያንዳንዱ OmniRoute ዩኒት `KillMode=mixed` ያለው drop-in
(`/etc/systemd/system/actions.runner.diegosouzapw-OmniRoute.<name>.service.d/10-killmode.conf`)
