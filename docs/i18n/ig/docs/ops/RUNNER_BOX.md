Pool a na-akwado n'onwe ya na-agba n'igwe **.113** (`tomni-proxmox-113`). Kemgbe 2026-10-18, runner
OmniRoute ọ bụla nwere **otu ọrụ**, otu label, yana oke ebe nchekwa/CPU ahaziri dabere n'ihe ibu ọrụ ya
tụtara. Slot Turbopack na-enweta ihe build chọrọ; a haziri slot ndị ọzọ dịka
ogo kachasị elu ha tụrụ. Igwe ahụ na-eji akụrụngwa karịrị nke o nwere naanị mgbe build Turbopack dakọtara na build webpack
Release-Green na ọrụ lint; swap nke host (16 GB) na-anabata nke ahụ, ebe ọ bụkwa na build nke pull-request na-agba
na sistemụ hosted, slot Turbopack anaghị arụ ọrụ ọtụtụ oge:

| runner               | label          | ọrụ                                                                                                                                                | `MemoryHigh` / `MemoryMax` | `CPUQuota`       |
| -------------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- | ---------------- |
| `omniroute-113-5`    | `omni-build`   | build Turbopack: `ci.yml` `Build` (naanị push/dispatch), Docker amd64, `npm-publish`, `nightly-v4-build`, `preview-artifact`, build a11y nke abalị | 56 GB / 60 GB (swap 0)     | 1600 %           |
| `omniroute-113-6`    | `omni-release` | Release-Green (`release-green` + `main-green`), build webpack                                                                                      | 20 GB / 24 GB (swap 4 GB)  | 800 %            |
| `omniroute-113-2`    | `omni-light`   | ọrụ abalị (Schemathesis, promptfoo, garak, k6, mbido a11y) na `quality.yml` `lint-guard`                                                           | 12 GB / 16 GB (swap 4 GB)  | 600 %            |
| `omniroute-113`      | `omni-light`   | otu pool ahụ dị n'elu                                                                                                                              | 8 GB / 12 GB               | 400 %            |
| OmniHeuris, OmniMind | (repo ha)      | Naanị Dependabot (ogo kachasị elu 155 MB nke ọ bụla, 2026-10-18)                                                                                   | 4 GB / 6 GB                | 200 % nke ọ bụla |

Ihe a tụrụ na 2026-10-18:

| akụrụngwa | uru                       | ihe ọ pụtara maka ịhazi oge                                                                                                                                                                                                                                                                                                                                                                                           |
| --------- | ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| RAM / CPU | **78 GB / core 32**       | build Turbopack production ruru ogo kachasị elu 49 GB mgbe enweghị oke (`tests/unit/ci-build-bundler-webpack.test.ts`); na Next 16.3.8, naanị akụkụ compile na-ejide ihe dịka 40 GB (36 GB RSS n'ime `next-build` tinyere worker loader 17 na 3 GB, nke a tụrụ na 2026-10-18); build webpack na-eji ihe dịka 14–16 GB. Otu build Turbopack + otu build webpack nwere ike ịgbakọ ọnụ; build Turbopack abụọ enweghị ike |
| swap      | 16 GB                     | `omniroute-113-5` na-agba mgbe agbanyụrụ swap (`MemorySwapMax=0`) ka e wee kwụsị build gbapụrụ oke n'ogo e nyere ya kama ime ka igwe ahụ jiri swap                                                                                                                                                                                                                                                                    |
| `/tmp`    | **12 GB tmpfs = RAM**     | ihe ọ bụla echekwara ebe ahụ bụ ebe nchekwa; a na-ekpochapụ ihe fọdụrụ mgbe awa 3 gachara                                                                                                                                                                                                                                                                                                                             |
| CPU       | a hụrụ load 60 na core 32 | tupu e tinye oke ndị ahụ, otu build Turbopack (~1166 % CPU) tinyere suite coverage n'otu igwe ahụ gbochiri heartbeat nke listener ndị ọzọ (`The self-hosted runner lost communication`, #16853)                                                                                                                                                                                                                       |
| runners   | **listener 6**            | OmniRoute 4 + OmniHeuris + OmniMind; agbanyụrụ `omniroute-113-3/-4/-7/-8` (`systemctl enable --now` na-eweghachite otu)                                                                                                                                                                                                                                                                                               |

Oke ndị ahụ dị na `/etc/systemd/system/actions.runner.<…>.service.d/override.conf` nke unit ọ bụla
(e debere uru ndị gara aga dịka `override.conf.bak-20261018`) ma tinye ha ozugbo site na
`systemctl set-property --runtime … MemoryHigh=… MemoryMax=… CPUQuota=…` — enweghị restart, ya mere e metụghị
ọrụ ọ bụla na-agba ọsọ aka. A na-agbanwe label site na API nke runner
(`gh api -X DELETE repos/<repo>/actions/runners/<id>/labels/<label>` /
`gh api -X POST repos/<repo>/actions/runners/<id>/labels -f 'labels[]=<label>'`), ozugbo kwa.

## Wụnye onye na-ehicha ihe (otu ugboro, na igwe ahụ)

```bash
scp scripts/ops/runner-janitor.sh root@192.168.0.113:/opt/omniroute-ops/runner-janitor.sh
ssh root@192.168.0.113 'chmod +x /opt/omniroute-ops/runner-janitor.sh; apt-get install -y lsof'
# cron (root): kwa nkeji 30, dekọọ na /var/log/runner-janitor.log
*/30 * * * * MAX_ACTIVE_RUNNERS=6 /opt/omniroute-ops/runner-janitor.sh >> /var/log/runner-janitor.log 2>&1
```

A chọrọ `lsof`: onye na-ehicha ihe na-eji otu snapshot nke faịlụ ndị mepere emepe
gosi na path anaghị arụ ọrụ tupu o wepụ ya, ma ọ bụrụ na ngwá ọrụ ahụ adịghị, ọ naghị
ewepụ ihe ọ bụla ma na-ekwukwa nke ahụ (exit 1). Buru ụzọ jiri `--dry-run` nwalee mgbanwe
ọ bụla — ọ na-ebipụta kpọmkwem ihe ọ ga-eme ma ọ naghị emetụ ihe ọ bụla aka.

Ihe ọ na-eme na run ọ bụla: ọ na-ekpochapụ ihe ndị nke anyị fọdụrụ (`runner-*`, `omniroute-*`,
`next-build*`, `e2e-build.tar.gz`) mgbe **awa 3 na tmpfs** gasịrị nakwa awa 24 na disk
`_work/_temp`; ọ na-akwụsị `next-build` nke karịrị nkeji 75 (ọ dịghị job na-agba ogologo oge ahụ — na
2026-08-27, otu gbara nkeji 70 mgbe GitHub kwupụtachara na job ya efuola); ọ na-ehichapụ
checkout ndị dị awa 48 nke runner ndị unit ha **kwụsịrị**; ọ na-enye ọkwa mgbe disk ≥ 85 %, memory PSI
`full/avg60` ≥ 10 %, nakwa mgbe listeners karịrị `MAX_ACTIVE_RUNNERS` (ya na nkewa
omniroute/ndị ọzọ). Exit 1 = e kwesịrị ilebara ya anya; gụọ log ahụ.

Iwu nkeji 75 ahụ anaghị achọpụta build nke GitHub kwụsịrị ịtụ anya job ya. Mgbe
`Runner.Listener` na-enweghị ike ime renewal nke job ya, `_diag/Runner_*.log` na-egosi
`POST request to …/renewjob timed out after 100 seconds`, API na-akọ na job ahụ bụ `completed`
(failure) ihe dị ka nkeji iri mgbe renewal ikpeazụ gara nke ọma, ebe `next-build` na-aga n'ihu na-agba
n'enweghị job e jikọtara na ya (2026-10-18: Build nke #17066 dara na 19:43 ma build ya ka
na-ejide 40 GB nkeji ise ka e mesịrị). Kwenye ref ahụ na `_diag/Worker_*.log` kacha ọhụrụ, wee jiri
SIGTERM kwụsị naanị build tree site na PID — `next-build`, `npm run build`, `build-next-isolated.mjs` na
workers ndị dị na `_work`. Emetụla `Runner.Listener`, `RunnerService.js` ma ọ bụ `Runner.Worker` aka:
worker ahụ na-akọ na a kagbuola job ahụ, listener ahụ ana-alaghachikwa online n'onwe ya.

## Yuniti runner: KillMode

`KillMode=process` ndabara nke runner na-ahapụ `Runner.Worker → npm → next-build`
ka ọ dị ndụ mgbe a kwụsịrị ma ọ bụ malitegharịa yuniti — build na-enweghị onye nwe ya na-aga n'ihu iri RAM na
CPU n'agbanyeghị na ọ dịghị job jikọrọ ya. Yuniti OmniRoute ọ bụla nwere nhazi mgbakwunye
(`/etc/systemd/system/actions.runner.diegosouzapw-OmniRoute.<name>.service.d/10-killmode.conf`)
nke nwere `KillMode=mixed`: SIGTERM na-aga na listener na mbụ, SIGKILL agakwuru cgroup niile mgbe
`TimeoutStop` ruru. Ọ ga-amalite ịrụ ọrụ na restart yuniti na-esote — malitegharịa **otu runner n'otu
oge, naanị mgbe ọ nọghị n'ọrụ**, jiri otu command ahụ mee nyocha idle na restart.

## Iwu ọrụ

- **Otu build Turbopack naanị n’otu oge — a na-amanye nke a site na label.** Job ọ bụla na-eme build Turbopack zuru ezu
  `next build` na-ezubere `[self-hosted, omni-build]`, ma ọ bụ naanị **`omniroute-113-5`** nwere
  label ahụ: `ci.yml` `Build`, `npm-publish.yml` `publish`, `nightly-v4-build`, `preview-artifact`,
  build a11y nke abalị (#16853) na `docker-publish.yml` **amd64** (webpack n’ime BuildKit —
  Turbopack dara ebe ahụ, run 33253576569). Akụkụ Docker arm64 ka na-agba na `ubuntu-24.04-arm`.
  `docker-publish` amd64 na `ci.yml` `Build` na-ekekọrịta concurrency group `heavy-build-main`
  (`cancel-in-progress: false`). Docker Engine ga-adịrịrị na `omniroute-113-5`. Slot Turbopack
  nke abụọ agaghị aba na 78 GB (2 × 33–37 GB tinyere ihe ndị ọzọ dị na igwe ahụ); slot nke abụọ
  dị nchebe naanị maka build webpack.
- **Build nke pull request na-agba na hosted runner (2026-10-18).** `ci.yml` `Build` na-erute
  `omni-build` naanị maka `push` na `workflow_dispatch`; `pull_request` ọ bụla (nke sitere n’otu
  origin ma ọ bụ fork) na Build `merge_group` na-agba na `ubuntu-latest` site na webpack. Mgbe
  e zigara PR ọ bụla sitere n’otu origin na slot ahụ, otu Build Turbopack jidere ya nkeji 29–58,
  Build 18 nọ n’ahịrị ruo awa 18, ebe push Build nke release line n’onwe ya nwetara slot ahụ naanị
  otu ugboro n’ime job 40. Na hosted runner, otu PR Build ahụ na-ewe nkeji 8–12 n’akụkụ job ndị ọzọ
  nke PR ahụ. A ka na-anwale Turbopack, bundler nke `npm-publish` na-ebipụta, na release line site
  na build a11y nke abalị nke default branch (04:41 UTC), site na push ma ọ bụ dispatch Build ọ bụla
  rutere slot ahụ, nakwa site na `npm-publish` n’onwe ya. `tests/unit/build/heavy-build-queue.test.ts`
  na-edobe gate nwere clause anọ ahụ.
- **Ebelatala nha slot Turbopack n’okpuru mkpa a tụrụ.** Na 2026-10-18 n’elekere 18:06, e belatara
  slot ahụ site na 56G/60G ruo 40G/44G iji mepụta ohere maka `omni-release`. Akụkụ compile ahụ nọgidere
  na `MemoryHigh` n’oge run ya niile (memory PSI `full` 30–43 %), ma `Runner.Listener`, nke ya na ya
  na-ekekọrịta cgroup, enweghị ike imegharị job ya. E weghachiri 56G/60G nke onye nwe ya nke
  2026-10-17 n’otu ụbọchị ahụ. N’okpuru uru ahụ, build ahụ anaghị ada; ọ na-amalite thrashing,
  e wee tufuo job ahụ.
- **Release-Green nwere slot nke ya (2026-10-18).** Tupu mgbe ahụ, validation Release-Green abụọ ahụ
  na-agba na `omni-build`: na push ọ bụla (~10/hour, a kagburu 97 n’ime push run 100 n’etiti ọrụ
  n’otu ụbọchị) na full sweep atọ nke na-ewe ihe dị ka awa 2 kwa ụbọchị (sweep nke 05:29 chere awa 6
  maka slot ahụ) — e nyere otu build slot ahụ ọrụ karịrị ike ya ọtụtụ ugboro, Build PR sitere n’otu
  origin wee chere ọtụtụ awa. `release-green` na `main-green` na-ezuberezi `omni-release`
  (`omniroute-113-6` naanị) site na `OMNIROUTE_USE_TURBOPACK=0`, a naghịzi akagbu run amalitela mgbe
  push ọhụrụ bịara (slot pending ahụ ka na-achịkọta oke push ndị ahụ).
  `tests/unit/build/runner-capacity-routing.test.ts` na-edobe routing ahụ, mgbanwe webpack ahụ,
  nakwa na ọ dịghị ihe dị na `omni-release` na-eji Turbopack eme build.
- **Pool dị mfe: `omni-light`.** `omniroute-113` na `omniroute-113-2` na-agba nightlies ndị chọrọ
  `next build` nke backend naanị (~5–6 GB; webpack) na `quality.yml` `lint-guard`. `omniroute-113`
  nwere `MemoryHigh=4G` ruo 2026-10-18 — build promptfoo ji nkeji 54 na-eme reclamation ebe ahụ;
  8 GB na-ewepụ throttling ahụ.
- **A kpachapụrụ anya mee ka listener dị ole na ole.** E gbanyụrụ unit OmniRoute anọ na 2026-08-29 —
  listener ọzọ ọ bụla bụ tenant ọzọ na memory budget dị n’elu. Oke janitor bụ 6
  (`MAX_ACTIVE_RUNNERS=6` n’ime cron): ọ na-agụ `Runner.Listener` ọ bụla dị n’igwe ahụ, ebe
  OmniHeuris + OmniMind na-agbakwụnye abụọ na anọ nke anyị.
- **Ejila aka hichaa `/tmp` ma ọ bụ `_work` mgbe runner ọ bụla ka na-arụ ọrụ.** Usoro
  check-then-delete nwere oghere oge n’etiti nzọụkwụ abụọ ahụ mere ka job Build na-agba ọsọ tufuo
  `_work` ya na 2026-08-27. Janitor na-eme nyocha na mwepụ ahụ n’otu nzọụkwụ;
  hapụ ya ka o mee ya.
- Ịkwụsị runner n’etiti job na-akagbu job ahụ (a hụrụ ya ozugbo): jiri `systemctl stop` naanị
  mgbe listener ya enweghị child `Runner.Worker` — ma mee ya n’otu command.
- Workflow agaghị edowe artefact na `/tmp` (ọ bụ RAM). Budata ya na
  `$RUNNER_TEMP` (dị na diski, nke runner ọ bụla) — artefact `next-build` nke 1.3 GB were nkeji 27–32
  iji rute na tmpfs, ma were nkeji 2 iji si na diski upload.
- VPS `.15` bụ naanị maka homologation — ọ dịghị mgbe ọ na-agba CI runner.
