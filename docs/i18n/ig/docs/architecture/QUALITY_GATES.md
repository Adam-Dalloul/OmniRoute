Akwụkwọ a bụ ntụaka kachasị ikike maka ọnụ ụzọ ogo CI niile dị na OmniRoute.
Ọ na-akọwa ọnụ ụzọ ọ bụla, ihe ọ na-enyocha, ọrụ CI ọ na-arụ n'ime ya, ma ọ na-eji
ntọala ratchet ma ọ bụ iwu ngafe/ọdịda, yana ma ọ na-egbochi build ka ọ bụ naanị ndụmọdụ.

Maka nchịkọta dị mkpirikpi na iwu allowlist, lee ngalaba "Quality Gates & Ratchets"
dị na `AGENTS.md`. Maka nyocha dị mkpa, nhazi ọkwa ntozu-oke, na atụmatụ mmegharị
nke otu sistemụ ahụ na-adabereghị na ngwá ọrụ ọ bụla, lee
[Quality Gate Playbook](../ops/QUALITY_GATE_PLAYBOOK.md).

## Ndepụta ọnụ ụzọ na profaịlụ mmezu

### Nnabata onye ndoro-ndoro

Usoro ọrụ CI na Quality Gates nke ọ bụla na-ewepụta mkpebi kwụsiri ike: `Gate / CI` na
`Gate / Quality`. Iwu nnabata ha nwere ụdị e depụtara na-akọwapụta ọrụ upstream ọ bụla
dị ka nke a chọrọ ma ọ bụ nke ndụmọdụ. Ọrụ achọrọ nke dabara adaba ga-aga nke ọma: nsonaazụ
na-efu efu, nke a kagburu, nke a mafere, nke ka na-echere na nke a na-amaghị enweghị ike igosi PASS. Nkewa
docs-only ma ọ bụ catalog-only ziri ezi nwere ike ime ka lane koodu ghara ịdị mkpa;
draft PR abụghị onye ndoro-ndoro a nabatara. Label `hotfix` anaghị ewepụ mkpa ihe akaebe.

Usoro ọrụ abụọ ahụ na-ekpuchi PR na push gaa na alaka main/release, manual dispatch na
merge-group events. Push, dispatch na merge-group na-eme nhọrọ zuru ezu. Fork
na merge group na-eji hosted runners maka ọrụ ndị gaara ahọrọ self-hosted
runners; a ga-enyocharịrị na hosted capacity zuru ezu tupu rollout.

Receipt JSON ọ bụla na-akọwapụta SHA e wepụtara, workflow run na attempt.
CLI na-ajụ ma SHA nke checkout/event ekwekọghị. Workflow tests na-ejikọta ịbụ onye otu policy
na ndepụta `needs` nke verdict job ka lane ọhụrụ ma ọ bụ nke ewepụrụ ghara ịla n'iyi na nzuzo.
Receipt ndị ahụ na-ekpuchi workflow nke ha, ọ bụghị publication, deployment, ma ọ bụ ihe dị n'ime
advisory scanner dị adị. Ime ka check name abụọ ahụ rụọ ọrụ na branch rules bụ
mgbanwe nchịkwa dị iche; ịgbakwunye ọrụ ndị a anaghị echebe branch n'onwe ya.

### Ndepụta static scan

Ndepụta npm-alias nwere ụdị e depụtara na ịbụ onye otu static-scan dị na
`config/quality/gate-manifest.json`. Gbaa `npm run check:gate-manifest` iji kwado
aha script na command kpọmkwem megide `package.json`; mgbakwunye, mwepụ na
mgbanwe command na-eme ka ma local hook ma change-classification jobs dị na CI daa.
Alias abụghị workflow job, matrix instance ma ọ bụ test case: e kwesịghị
igosi ọnụ ọgụgụ ndị a dịka ihe a pụrụ iji dochie ibe ha.

Jiri `npm run quality:scan -- --list` ma ọ bụ `npm run quality:scan:fast -- --list`
iji nyochaa alias ndị ahọpụtara n'emeghị ha. Runner na-akpọ
npm entrypoint, ya mere a na-echekwa runtime ya (gụnyere Bun ebe a haziri ya).
Manifest na-edekọ alias ndị na-abụghị akụkụ profaịlụ ndị ahụ dịka ndị a na-akpọ iche iche, a
machibidokwara maintenance commands n'ime profaịlụ scan nke read-only.

Profaịlụ ndị a na-ekpuchi naanị static scan. Ha anaghị akwado product tests,
coverage, packaging, external checks ma ọ bụ nnabata release zuru ezu nke onye ndoro-ndoro.
Workflow admission na-eji `config/quality/admission-policy.json` ejikọrọ na
`scripts/quality/admission-verdict.mjs`. Profaịlụ release-observer ka dị iche;
nyochaa check na receipt ha ndị dabara adaba n'adabereghị na ndị ọzọ. Ndepụta e dere
n'okpuru bụ ntụaka, ọ bụghị ihe akaebe na gate gbara ọsọ n'ezie.

Script dị n'okpuru `scripts/check/` (policy gates) na `scripts/quality/` (ratchet engine).
Isi iyi eziokwu nke CI bụ `.github/workflows/ci.yml`.

### Ụzọ ngwa ngwa nke Release PR (`quality.yml`)

`.github/workflows/quality.yml` na-emeju CI na main/release PRs, push gaa na protected-branch,
dispatch na merge groups. PR na-eji fast checks ndị a nyochara site na path. E wepụrụ duplicate build
nke agbanyụrụ kpamkpam; ezigbo build/package/boot checks ka dị na CI.

| Ọrụ                                              | Oke                                                                                                                                                                                            | Na-egbochi        |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| `Docs Gates (fast-path)`                         | Docs/code PRs; API docs refs na docs-all                                                                                                                                                       | Ee                |
| `Fast Quality Gates`                             | Code PRs; static checks, typecheck, dashboard typecheck, impacted unit tests                                                                                                                   | Ee                |
| `Forgotten sibling tests`                        | Code PRs; a na-esochi changed modules ruo static consumers na candidate sibling tests; a na-akọ barrel na dynamic-import paths dịka advisory diagnostics, yana referenced allowlist exceptions | **Ndụmọdụ**       |
| `Vitest (fast-path)`                             | Code PRs; fast vitest suite                                                                                                                                                                    | Ee                |
| `Unit Tests fast-path`                           | Code PRs; 4-shard unit suite                                                                                                                                                                   | Ee                |
| `No new ESLint warnings`                         | Code PRs; suppressions-aware lint guard                                                                                                                                                        | Ee, gụnyere forks |
| `Merge integrity (changelog + generated skills)` | Non-draft PRs; changelog na generated skill sync                                                                                                                                               | Ee, gụnyere forks |

#### Akụkọ Forgotten sibling tests

`npm run check:forgotten-sibling-tests` na-eji ọzọ import resolver dị n'azụ test-impact map.
Maka production module ọ bụla gbanwere, ọ na-akọ usoro ndị doro anya nke
`changed module/symbol -> static consumer -> candidate sibling test` mgbe candidate
test adịghị na pull-request diff. A na-edowe nchịkọta Markdown na nsonaazụ JSON dịka
workflow artifact `forgotten-sibling-tests` maka calibration tupu blocking rollout ọ bụla.

Mbupụgharị barrel na mbubata dynamic bụ naanị nyocha mkpebi ụzọ; ha anaghị emepụta nchọpụta na-egbochi ihe.
Ewezuga ndị enyochara dị na
`config/quality/forgotten-sibling-allowlist.json`. Ndenye ọ bụla ga-akpọrịrị consumer na ule candidate,
nye kpọmkwem ihe kpatara ya, ma jikọta issue ma ọ bụ pull request GitHub. Ndenye ndị ahaziri n'ụzọ na-ezighi ezi na-eme
ka usoro jụ ha. Ewezuga agaghị egbochi nchọpụta ule candidate ehichapụrụ ma ọ bụ diff nke na-agbakwunye `.skip`/`.todo`;
ime ka assertion ghara isi ike na ụzọ mkpuchi ndị ọzọ ka bụ ọrụ nke gate
`check:test-masking` nke na-egbochi ihe n'onwe ya.

#### `check-ui-value-drift` — ọnụ ụzọ nyocha ntụgharị asụsụ ochie

Ọ na-achọpụta otu ndaghachi azụ i18n nke ọnụ ụzọ nyocha ndị ọzọ enweghị ike ịhụ n'ụzọ nhazi: a na-edegharị uru Bekee
ma ntụgharị asụsụ ndị e si na Bekee _gara aga_ nweta ka na-adị, ya mere
ndị ọrụ na-abụghị ndị Bekee ka na-agụ ederede e ji obi ike dee ma nke na-ezighi ezi ugbu a.

Nke a mere n'ezie na mbipụta. E degharịrị `oauthModal.googleOAuthWarning` mgbe enyemaka nbanye Antigravity
bịara (#5203); **39 n'ime mpaghara 43** ka nwere ederede na-agwa ndị na-ahụ maka sistemụ ka ha "detuo
URL zuru ezu ma mado ya n'okpuru" — usoro na-enweghị ike ịga nke ọma maka onye na-eweta ọrụ ahụ. A
hụghị ya ruo #8463 n'ihi na:

- `sync-ui-keys` na-agbakwụnye naanị igodo ndị **na-adịghị**, ọ naghị agbakwụnye ndị **ochie**;
- `check-ui-keys-coverage` na-agụ ọnụnọ igodo, ya mere a na-agụ ntụgharị asụsụ ochie dị ka nke e kpuchiri;
- `check-translation-drift` na-enyocha oyiri akwụkwọ `docs/i18n/<locale>/**.md` —
  ọ naghị agụ `src/i18n/messages/*.json` ma ọlị. Ọ na-egbochi na ọrụ `docs-sync-strict` kemgbe
  mmekọrịta ọzọ nke 2026-09: dezie akwụkwọ isi → `npm run i18n:run -- --files=<doc>` (n'ọkwa ngalaba, dị ọnụ ala).

**Ọ na-elebara diff anya, ọ naghị adabere na baseline.** Ọ na-atụnyere `en.json` dị na merge base na
working tree; maka key ọ bụla uru Bekee ya gbanwere, locale ọ bụla ka nwere
ntụgharị a na-emetụghị aka abụrụla nke ochie. Nke a kpachaara anya **na-akpụkọta ụgwọ dịbu adị** — diff
enweghị ike igosi Bekee ochie nke ntụgharị dịteworo aka si na ya pụta, ya mere gate ahụ na-enyocha
naanị ihe mgbanwe dị ugbu a metụrụ. Nhọrọ ọzọ (baseline hash maka key ọ bụla) ga-achọ
faịlụ emepụtara nke dị ihe dị ka 600 KB, okpukpu 3 nke baseline kacha ibu dị ugbu a, ma na-agbanwe n'oge PR i18n ọ bụla.

Ụzọ abụọ iji mezuo ya:

1. melite ntụgharị ndị o metụtara, ma ọ bụ
2. tọọ ha ka ha bụrụ `__MISSING__:<new english>` — runtime ahụ ga-enyezi Bekee edoziri
   (`src/i18n/request.ts::deepMergeFallback`, #7258), key ahụ abanye n'ahịrị ntụgharị.

Ọ bụrụ na **ihe eriri ahụ pụtara** agbanweela, họrọ **ịgbanwe aha key ahụ**: key ọhụrụ enweghị ike iketa
ntụgharị nke ochie. Nke ahụ bụ ụkpụrụ #8463 jiri.

```bash
npm run i18n:check-value-drift          # siri ike (ihe CI na-agba)
npm run i18n:check-value-drift:warn     # naanị mkpesa
BASE_REF=origin/release/vX.Y.Z npm run i18n:check-value-drift
```

Ọ na-eji 0 kwụsị, ya na `SKIP reason=base-unresolved`, mgbe enweghị ike ịgụ base catalog ahụ (shallow
clone na-enweghị base ref), dịka `check-openapi-breaking` si eme.

**Ọnọdụ koodu ọhụrụ (Clean-as-You-Code) — kemgbe 2026-08-30, naanị ụzọ-ngwa-ngwa PR**

Na event `pull_request`, `quality.yml` na-enyefe `--base-ref <PR base SHA>` na `check:file-size`,
`check:complexity-ratchets` na `check:dead-code`. Maka `check:complexity-ratchets` na
`check:dead-code`, ọnụ ụzọ ahụ na-atụnyere HEAD na merge-base **n'oke naanị faịlụ ndị PR
metụrụ** (`scripts/check/newCodeMode.mjs`: a na-emepụta merge-base n'ime
`git worktree` a na-atụfu mgbe e jiri ya rụọ ọrụ, ESLint/knip na-agba ebe ahụ nakwa na HEAD, a na-ewerekwa ọdịiche dị n'ọnụọgụ kwa faịlụ):

- **na-egbochi** — PR ahụ gbakwunyere mmebi cyclomatic/cognitive ma ọ bụ dead exports na faịlụ ndị ọ gbanwere
  (`complexityNewCode=`, `cognitiveComplexityNewCode=`, `deadExportsNewCode=` n'ime log);
- **ndụmọdụ** — mkpokọta zuru ụwa ọnụ ma e jiri ya tụnyere baseline akpọchiri. Drift e ketara anaghị eme ka
  PR na-enweghị mmehie ghọọ uhie; a na-akpọchi drift ahụ ọzọ n'oge mmezi release, ọrụ headroom
  na-enyochakwa ya.

`check:file-size` na-eji base ref dịka iwu nke ya si dị (`scripts/check/check-file-size.mjs`, #8522):
ọ na-enyocha faịlụ source na test ọ bụla dị na tree, na-eji `git show` gụọ ọnụọgụ ahịrị nke ọ bụla

`check:boundary:ratchet` na-etinye otu iwu ahụ n'otu ọnụọgụ ya
(`scripts/quality/measure-boundary.mjs --ratchet --base-ref <sha>`): na mmemme PR, ma
ọnụ ụzọ-ngwa-ngwa `quality.yml` ma ọrụ lint nke `ci.yml` na-enyefe SHA ntọala PR ahụ, a na-atụ
commit ntọala ahụ site na mbupụ `git archive`, PR ahụ na-ada naanị mgbe ọnụọgụ njikọ
`open-sse → src` ya karịrị nke kachasị ukwuu n'etiti `metrics.boundaryOpenSseToSrc` na ọnụọgụ
dị na ntọala ahụ. A na-akọ ngafe ntọala gafere oke ahụ (`base drift herdado`) mana ọ dịghị mgbe
ọ na-eme ka PR na-enweghị mmejọ daa; push → main na-edobe oke zuru ezu ahụ, ebe SHA ntọala

## Ịchekwa Mbelata Ratchet — ụzọ mgbada (#8584)

Ratchet ahụ bụ naanị ọkara akpaaka, ọ bụkwa ọkara na-ezighi ezi. **Ibulite** cap bụ

## Iwu Ndepụta Ikike

Ọnụ ụzọ nyocha ọ bụla nke na-agaghị ada n’ihi mmebi ndị dịbu adị na-eji ndepụta ikike a kpọchiri akpọchi

**Dozie isi ihe kpatara nsogbu ahụ; jiri ndepụta ikike naanị mgbe mmebi ahụ dịbu adị ma
enweghị ike idozi ya n’otu PR ahụ.**

Mgbe ị na-agbakwunye ntinye na ndepụta ikike:

1. Tinye nkọwa na-akọwa ihe mere e ji mee ya.
2. Rụtụ aka n’okwu nlekota ahụ (dịka, `// #3498 — Njirimara Phase 2, emebebeghị ya`).
3. Wepụ ntinye ahụ n’otu PR ahụ nke na-edozi mmebi ahụ — ntinye ochie nke na-anaghịzi
   egbochi mmebi na-arụ ọrụ bụkwa ntụpọ (mmanye iwu megide ntinye ochie nke 6A.3 ga-eme ka
   ọnụ ụzọ nyocha ahụ daa n’ihi ntinye ndepụta ikike na-enweghịzi ihe ọ metụtara ozugbo etinyere ya n’ọrụ).

**Etinyela** ntinye na ndepụta ikike iji mee ka ule gafee ngwa ngwa. Ọnụ ụzọ nyocha na-acha akwụkwọ ndụ ebe
ndepụta ikike na-aga n’ihu na-eto eto na-enye echiche ụgha banyere ịdịmma.

### Mgbe ọnụ ụzọ nyocha dara na PR gị

1. **Jiri nlezianya gụọ nsonaazụ ọnụ ụzọ nyocha ahụ** — ọ na-agwa gị kpọmkwem faịlụ ma ọ bụ akara nke
   mebiri iwu ahụ.
2. **Dozie mmebi ahụ** — ọtụtụ ọnụ ụzọ nyocha bụ nlele sistemụ faịlụ a kara aka nke na-agafe ozugbo
