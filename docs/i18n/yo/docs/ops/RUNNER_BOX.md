Pool tí a gbàlejò fúnra wa ń ṣiṣẹ́ lórí ẹ̀rọ **.113** (`tomni-proxmox-113`). Láti 2026-10-18, runner OmniRoute kọ̀ọ̀kan ní **ipa kan ṣoṣo**, label kan, àti ìwọ̀n memory/CPU tí a ṣètò gẹ́gẹ́ bí ohun tí workload rẹ̀ lò nígbà ìwọ̀n. Ààyè Turbopack ń gba ohun tí build náà nílò; a sì ṣètò àwọn ààyè yòókù gẹ́gẹ́ bí àwọn peak tí a wọn fún wọn. Ẹ̀rọ náà kàn ń ṣe overcommit nígbà tí build Turbopack bá ṣẹlẹ̀ papọ̀ pẹ̀lú build webpack Release-Green àti iṣẹ́ lint kan; swap host (16 GB) ló ń gba àfikún náà, àti nítorí pé àwọn Build pull-request ń ṣiṣẹ́ lórí hosted runner, ààyè Turbopack máa ń ṣòfo ní ọ̀pọ̀ jù lọ àkókò:

| runner               | label           | ipa                                                                                                                                               | `MemoryHigh` / `MemoryMax` | `CPUQuota`        |
| -------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- | ----------------- |
| `omniroute-113-5`    | `omni-build`    | Àwọn build Turbopack: `ci.yml` `Build` (push/dispatch nìkan), Docker amd64, `npm-publish`, `nightly-v4-build`, `preview-artifact`, build a11y alẹ́ | 56 GB / 60 GB (swap 0)     | 1600 %            |
| `omniroute-113-6`    | `omni-release`  | Release-Green (`release-green` + `main-green`), build webpack                                                                                     | 20 GB / 24 GB (swap 4 GB)  | 800 %             |
| `omniroute-113-2`    | `omni-light`    | àwọn iṣẹ́ alẹ́ (Schemathesis, promptfoo, garak, k6, boot a11y) àti `quality.yml` `lint-guard`                                                       | 12 GB / 16 GB (swap 4 GB)  | 600 %             |
| `omniroute-113`      | `omni-light`    | pool kan náà bí èyí tó wà lókè                                                                                                                    | 8 GB / 12 GB               | 400 %             |
| OmniHeuris, OmniMind | (àwọn repo wọn) | Dependabot nìkan (peak 155 MB fún ọ̀kọ̀ọ̀kan, 2026-10-18)                                                                                            | 4 GB / 6 GB                | 200 % fún ọ̀kọ̀ọ̀kan |

| ---------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |

Build Turbopack kan àti build webpack kan lè wọ̀ papọ̀; build Turbopack méjì kò lè wọ̀ |

Àwọn ààlà náà wà nínú `/etc/systemd/system/actions.runner.<…>.service.d/override.conf` ti unit kọ̀ọ̀kan
(a pa àwọn iye àtijọ́ mọ́ gẹ́gẹ́ bí `override.conf.bak-20261018`), a sì lò wọ́n ní live pẹ̀lú
`systemctl set-property --runtime … MemoryHigh=… MemoryMax=… CPUQuota=…` — kò sí restart, nítorí náà kò
sí iṣẹ́ tó ń ṣiṣẹ́ tí a fọwọ́ kàn. A ń yí àwọn label padà nípasẹ̀ API àwọn runner
(`gh api -X DELETE repos/<repo>/actions/runners/<id>/labels/<label>` /
`gh api -X POST repos/<repo>/actions/runners/<id>/labels -f 'labels[]=<label>'`), ní live pẹ̀lú.

## Fi olùtọ́jú ìmọ́tótó sílẹ̀ (ẹ̀ẹ̀kan ṣoṣo, lórí ẹ̀rọ náà)

```bash
scp scripts/ops/runner-janitor.sh root@192.168.0.113:/opt/omniroute-ops/runner-janitor.sh
ssh root@192.168.0.113 'chmod +x /opt/omniroute-ops/runner-janitor.sh; apt-get install -y lsof'
# cron (root): ní gbogbo ìṣẹ́jú 30, kọ àkọsílẹ̀ sí /var/log/runner-janitor.log
*/30 * * * * MAX_ACTIVE_RUNNERS=6 /opt/omniroute-ops/runner-janitor.sh >> /var/log/runner-janitor.log 2>&1
```

A nílò `lsof`: olùtọ́jú ìmọ́tótó náà máa ń fi àwòrán ìṣẹ́jú-kan ti àwọn fáìlì tí ó ṣí hàn pé path kan kò sí ní lílò
kí ó tó yọ ọ́ kúrò, àti láìsí irinṣẹ́ náà kò ní yọ ohunkóhun kúrò, yóò sì sọ bẹ́ẹ̀
(exit 1). Kọ́kọ́ dán ìyípadà èyíkéyìí wò pẹ̀lú `--dry-run` — ó máa tẹ ohun tí yóò ṣe gan-an jáde,
kò sì ní fọwọ́ kan ohunkóhun.

Ohun tí ó ń ṣe ní gbogbo ìṣiṣẹ́: ó ń pa àwọn ohun tó ṣẹ́ kù láti ọ̀dọ̀ wa (`runner-*`, `omniroute-*`,
`next-build*`, `e2e-build.tar.gz`) lẹ́yìn **wákàtí 3 lórí tmpfs** àti wákàtí 24 lórí disk
`_work/_temp`; ó ń pa `next-build` tí ó ti ju ìṣẹ́jú 75 lọ (kò sí job kankan tó máa ń ṣiṣẹ́ tó bẹ́ẹ̀ — ní
2026-08-27 ọ̀kan ṣiṣẹ́ fún ìṣẹ́jú 70 lẹ́yìn tí GitHub ti kéde pé job rẹ̀ ti sọnù); ó ń pa àwọn
checkout runner tí ó ti pé wákàtí 48, tí unit wọn sì ti **dúró**; ó ń fi ìkìlọ̀ ránṣẹ́ nígbà tí disk bá ≥ 85%,
memory PSI `full/avg60` bá ≥ 10%, àti nígbà tí iye àwọn listener bá ju `MAX_ACTIVE_RUNNERS` lọ (pẹ̀lú
ìpín omniroute/àwọn míì). Exit 1 = a nílò àkíyèsí; ka àkọsílẹ̀ náà.

Òfin ìṣẹ́jú 75 náà kò lè rí build tí GitHub ti jáwọ́ nínú job rẹ̀ tẹ́lẹ̀. Nígbà tí
`Runner.Listener` kò bá lè tún job rẹ̀ ṣe, `_diag/Runner_*.log` máa ń fi
`POST request to …/renewjob timed out after 100 seconds` hàn, API máa ń sọ pé job náà ti `completed`
(failure) ní nǹkan bí ìṣẹ́jú mẹ́wàá lẹ́yìn ìtúnṣe tó kẹ́yìn tó ṣàṣeyọrí, `next-build` sì máa ń bá a lọ láti ṣiṣẹ́
láìsí job tí a so mọ́ ọn (2026-10-18: Build ti #17066 ti kùnà ní 19:43, build rẹ̀ sì ṣì ń
di 40 GB mú ní ìṣẹ́jú márùn-ún lẹ́yìn náà). Jẹ́rìí ref náà nínú `_diag/Worker_*.log` tuntun jù lọ, lẹ́yìn náà
fi SIGTERM ránṣẹ́ sí igi build náà nìkan nípasẹ̀ PID — `next-build`, `npm run build`, `build-next-isolated.mjs` àti
àwọn worker `_work`. Má ṣe fọwọ́ kan `Runner.Listener`, `RunnerService.js` tàbí `Runner.Worker` láé:
worker náà máa ń jabo pé a ti fagilé job náà, listener náà sì máa ń padà sí online fúnra rẹ̀.

## Àwọn ẹ̀ka runner: KillMode

`KillMode=process` aiyipada ti runner máa ń fi `Runner.Worker → npm → next-build`
sílẹ̀ láàyè nígbà tí a bá dá ẹ̀ka kan dúró tàbí tún un bẹ̀rẹ̀ — build aláìní olùtọ́jú náà ń bá a lọ láti máa jẹ RAM àti
CPU láìsí iṣẹ́ kankan tí a so mọ́ ọn. Gbogbo ẹ̀ka OmniRoute ní drop-in kan
(`/etc/systemd/system/actions.runner.diegosouzapw-OmniRoute.<name>.service.d/10-killmode.conf`)
pẹ̀lú `KillMode=mixed`: SIGTERM sí listener lákọ̀ọ́kọ́, lẹ́yìn náà SIGKILL sí gbogbo cgroup ní
`TimeoutStop`. Ó máa bẹ̀rẹ̀ sí í ṣiṣẹ́ nígbà tí a bá tún ẹ̀ka náà bẹ̀rẹ̀ lẹ́ẹ̀kan sí i — tún **runner kan ṣoṣo bẹ̀rẹ̀
ní ẹ̀ẹ̀kan, nígbà tí kò bá ṣiṣẹ́ nìkan**, pẹ̀lú àyẹ̀wò pé kò ṣiṣẹ́ àti àtúnbẹ̀rẹ̀ náà nínú command kan náà.

## Àwọn òfin ìṣiṣẹ́

- **Ìkọ́lé Turbopack kan ṣoṣo lẹ́ẹ̀kan — a fi àmì àkọlé mú un ṣẹ.** Gbogbo iṣẹ́ tó ń ṣiṣẹ́ ìkọ́lé Turbopack kíkún
  `next build` ni a darí sí `[self-hosted, omni-build]`, `omniroute-113-5` **nìkan** sì ni
  àmì àkọlé yẹn: `ci.yml` `Build`, `npm-publish.yml` `publish`, `nightly-v4-build`, `preview-artifact`,
  ìkọ́lé a11y alẹ́ (#16853) àti `docker-publish.yml` **amd64** (webpack nínú BuildKit —
  Turbopack jákulẹ̀ níbẹ̀, ìṣiṣẹ́ 33253576569). Ẹ̀ka Docker arm64 ṣì wà lórí `ubuntu-24.04-arm`.
  `docker-publish` amd64 ń pín ẹgbẹ́ concurrency `heavy-build-main` pẹ̀lú `ci.yml` `Build`
  (`cancel-in-progress: false`). Docker Engine gbọ́dọ̀ wà lórí `omniroute-113-5`. Ààyè Turbopack
  kejì kò lè gba inú 78 GB (2 × 33–37 GB pẹ̀lú ìyókù ẹ̀rọ náà); ààyè kejì dáàbò bo fún
  àwọn ìkọ́lé webpack nìkan.
- **Àwọn ìkọ́lé pull-request ń ṣiṣẹ́ lórí olùpèsè (2026-10-18).** `ci.yml` `Build` dé `omni-build` nìkan fún
  `push` àti `workflow_dispatch`; gbogbo ìkọ́lé `pull_request` (láti orísun tirẹ̀ tàbí fork) àti `merge_group`
  ń ṣiṣẹ́ lórí `ubuntu-latest` pẹ̀lú webpack. Nígbà tí gbogbo PR láti orísun tirẹ̀ ni a darí sí ààyè náà, ìkọ́lé Turbopack
  kan máa ń dì í mú fún ìṣẹ́jú 29–58, àwọn ìkọ́lé 18 sì dúró ní ìlà fún tó wákàtí 18, ìkọ́lé push ti
  ìlà ìtújáde fúnra rẹ̀ sì rí ààyè náà lẹ́ẹ̀kan nínú iṣẹ́ 40. Lórí olùpèsè, ìkọ́lé PR kan náà gba ìṣẹ́jú
  8–12 lẹ́gbẹ̀ẹ́ àwọn iṣẹ́ PR yòókù. Turbopack, bundler tí `npm-publish` ń pín ká,
  ṣì ń gba ìdánwò lórí ìlà ìtújáde nípasẹ̀ ìkọ́lé a11y alẹ́ ti ẹ̀ka àkọ́kọ́ (04:41 UTC), nípasẹ̀
  gbogbo ìkọ́lé push tàbí dispatch tó dé ààyè náà, àti nípasẹ̀ `npm-publish` fúnra rẹ̀.
  `tests/unit/build/heavy-build-queue.test.ts` fi ẹnu-ọ̀nà oníṣèlẹ̀ mẹ́rin náà múlẹ̀.
- **Má ṣe dín ààyè Turbopack kéré ju ohun tí ìwọ̀n fi hàn pé ó nílò lọ.** Ní 2026-10-18 ní 18:06, a dín ààyè náà
  láti 56G/60G sí 40G/44G láti ṣí ààyè sílẹ̀ fún `omni-release`. Ìpele compile dúró ní
  `MemoryHigh` jálẹ̀ gbogbo ìṣiṣẹ́ rẹ̀ (memory PSI `full` 30–43 %), `Runner.Listener`, tó
  ń pín cgroup náà, kò sì lè tún iṣẹ́ rẹ̀ ṣe. A dá 56G/60G ti olówó rẹ̀ ti 2026-10-17 padà ní
  ọjọ́ kan náà. Ní abẹ́ iye yẹn, ìkọ́lé náà kì í kùnà; ó máa ń tiraka lọ́pọ̀lọpọ̀, iṣẹ́ náà sì máa ń sọnù.
- **Release-Green ní ààyè tirẹ̀ (2026-10-18).** Títí di ìgbà yẹn, àwọn ìfọwọ́sí Release-Green méjèèjì ń ṣiṣẹ́
  lórí `omni-build`: lórí gbogbo push (~10/wákàtí, 97 nínú 100 ìṣiṣẹ́ push ni a fagilé láàárín iṣẹ́ ní ọjọ́ kan)
  àti àyẹ̀wò kíkún mẹ́ta tó tó ~2 wákàtí lójoojúmọ́ (àyẹ̀wò 05:29 dúró fún wákàtí 6 láti rí ààyè náà) —
  a ń béèrè ju agbára ààyè ìkọ́lé kan ṣoṣo náà lọ ní ọ̀pọ̀ ìgbà, àwọn ìkọ́lé PR láti orísun tirẹ̀ sì dúró fún ọ̀pọ̀ wákàtí.
  `release-green` àti `main-green` ń tọ́ka sí `omni-release` báyìí (`omniroute-113-6` nìkan) pẹ̀lú
  `OMNIROUTE_USE_TURBOPACK=0`, a kò sì fagilé ìṣiṣẹ́ tó ti bẹ̀rẹ̀ mọ́ nítorí push tuntun
  (ààyè tó ń dúró ṣì ń kó ìgbì iṣẹ́ náà jọ). `tests/unit/build/runner-capacity-routing.test.ts`
  fi routing náà, ìyípadà webpack àti pé kò sí ohunkóhun lórí `omni-release` tó ń kọ́ pẹ̀lú Turbopack múlẹ̀.
- **Pool fẹ́rẹ̀ẹ́: `omni-light`.** `omniroute-113` àti `omniroute-113-2` ń ṣiṣẹ́ àwọn iṣẹ́ alẹ́ tó nílò
  `next build` fún backend nìkan (~5–6 GB; webpack) àti `quality.yml` `lint-guard`. `omniroute-113`
  ní `MemoryHigh=4G` títí di 2026-10-18 — ìkọ́lé promptfoo lo ìṣẹ́jú 54 níbẹ̀ ní pípa iranti padà;
  8 GB mú ìdíwọ́ ìṣiṣẹ́ náà kúrò.
- **Àwọn listener díẹ̀ ní ìmọ̀ọ́mọ̀.** A pa unit OmniRoute mẹ́rin ní 2026-08-29 — listener àfikún kọ̀ọ̀kan
  jẹ́ tenant míràn fún ìṣúná memory tó wà lókè. Òrùlé janitor jẹ́ 6 (`MAX_ACTIVE_RUNNERS=6` nínú cron): ó ń ka
  gbogbo `Runner.Listener` lórí ẹ̀rọ náà, OmniHeuris + OmniMind sì fi méjì kún mẹ́rin tiwa.
- **Má ṣe fọ `/tmp` tàbí `_work` mọ́ pẹ̀lú ọwọ́ nígbà tí runner èyíkéyìí bá dí.** Ìlànà
  ṣàyẹ̀wò-kí-o-tó-parẹ́ tó ní àlàfo láàárín àwọn ìgbésẹ̀ méjèèjì ló mú kí iṣẹ́ Build tó ń ṣiṣẹ́ pàdánù
